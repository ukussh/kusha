# Smooth Scroll Stories

I want that this project, while remaining responsiveness across all sorts of browsers, OS and screen resolutions, to be allowed to swipe.

I want that instead of clicking on the pages, I am able to move between them, through scrolling up or down. This switching in pages should be slow and smooth. Behaviour is:

Website opens up, with banner image as homepage always.
When scrolled bottom to top or right to left, move to next page which is about me, expertise, timeline, projects, contact. The homepage is to be named as main. 

Also fix the font sizes throughout the project, but especially in expertise page, such that the font remains consistent throughout the website while maintaining the responsiveness of the website.
Also thin the font, i.e reduce the font weight of the numbers in expertise page: 
08+
14M
120K
